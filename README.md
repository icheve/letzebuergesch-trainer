# Lëtzebuergesch 28

Мобильное PWA для персональной подготовки к экзамену по люксембуржскому языку 28 октября 2026 года.

Публикация: `https://icheve.github.io/letzebuergesch-trainer/`

## Что уже есть

- 39 карточек слов с интервальными повторениями;
- 73 проверенных персональных вопроса и ответа из PDF;
- 18 простых аналогичных фраз, отдельно помеченных как дополнительная практика;
- сборка предложений из перемешанных слов;
- устная симуляция экзамена с записью своего ответа;
- студийная озвучка слов из Lëtzebuerger Online Dictionnaire (LOD.lu);
- синтез речи телефона или браузера для персональных вопросов и ответов, которых нет в словаре;
- ежедневный план, серия занятий и локальная статистика;
- офлайн-режим после первого посещения.

## Запуск

```powershell
npm install
npm run dev
```

Production-сборка:

```powershell
npm run build
npm run preview
```

## Установка на телефон

Для установки PWA сайт должен быть опубликован по HTTPS. После публикации откройте адрес в браузере телефона и выберите «Установить приложение» или «На экран Домой». Прогресс хранится локально на конкретном устройстве.

## Добавление материалов

Новые PDF кладутся в соседнюю папку `люкс темы`. После проверки из них добавляются:

1. персональные вопросы и ответы;
2. русский перевод;
3. важные слова;
4. отдельные аналогичные упражнения.

Учебные данные находятся в `src/data/topics.ts`. Проверенные ответы и дополнительные фразы намеренно разделены.

У каждой карточки слова указан `lodId` официальной словарной статьи. Аудио воспроизводится напрямую с LOD.lu и требует подключения к интернету; остальные возможности PWA продолжают работать офлайн.
